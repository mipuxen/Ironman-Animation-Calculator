# Stark Calculator ⚡

Iron Man / J.A.R.V.I.S. mavzusidagi kalkulyator. Sof HTML + CSS + JavaScript, hech qanday kutubxonasiz.

Made by **Shuhratbek**.

## Xususiyatlar
- Animatsiyali nuqtali fon (kursorga javob beradi)
- Chizilib chiqadigan Iron Man dubulg'asi va arc reactor
- J.A.R.V.I.S. robot natijani "aytadi"
- Qavslar, foiz, xatolarni tekshirish
- Klaviatura bilan ishlaydi (raqamlar, `+ - * /`, `Enter`, `Backspace`, `Esc`)

## Ishga tushirish
`index.html` faylini brauzerda oching. Server kerak emas.

## GitHub Pages
Repo → **Settings** → **Pages** → Branch: `main` / `(root)` → Save.
